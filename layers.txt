# Allowed imports and SQL calls of each package of the repository, one line per package:
#   <package>: <imports allowed>
# Names are relative to the module path; database/sql is listed where SQL is allowed.
# A package whose line does not list database/sql may not call the database either
# (QueryContext, ExecContext, QueryRowContext, BeginTx, Exec, Query, QueryRow).
# An exception is a single import, or a file that calls the database, with its reason:
#   <package> -> <import>  # <reason>
#   <file path> -> sql  # <reason>
# Test files are not checked. A new package, a new import between packages and a
# new SQL call outside a repo need a change to this file, which only the owner's
# decision allows. An entry that nothing uses any more is reported; remove it.
# scripts/layers.sh compares this file with `go list`; make check runs it.
